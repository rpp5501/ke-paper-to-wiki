## Standing rules (inherit into every slice)

- **P1/R11:** no API keys ever; external APIs are opportunistic; everything must work with `RESEARCH_MCP_NO_APIS=1` (degraded honestly, never crashing).
- **P2:** deterministic scripts before LLM calls; LLM steps go through leased harness spawns (`claude -p`).
- **TDD:** every task = failing test first, watch it fail, minimal code, watch it pass, commit.
- **Fork-drift rule:** graphify changes = new isolated modules; upstream edits only when unavoidable and minimal.
- **Success-shaped failures:** tools return `status:` + hint, never raise, across every new surface.
- **Unicode:** `ensure_ascii=False` on all JSON that humans or grep will touch.
- **OneDrive caveat:** after editing large files, a stale mount read is possible in sandboxes; canonical state is the file-tool view. Verify with `py_compile` locally when in doubt.
- Dependencies pinned: `mcp>=1.2,<2` (v2 is pre-release with breaking changes — verified 2026-07-09), `pylatexenc>=2.10`, `selectolax>=0.3`, `markdown>=3.5`, `networkx>=3.0`.
