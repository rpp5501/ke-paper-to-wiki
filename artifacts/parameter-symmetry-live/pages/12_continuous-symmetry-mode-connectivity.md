# Continuous Symmetry and Mode Connectivity

## TL;DR {#tldr}
- A symmetry is continuous when its group $G$ is a Lie group acting continuously on parameter space; its orbits are then typically positive-dimensional manifolds sitting entirely inside one loss level set [§sec_3_1].
- Because the loss is constant along an orbit, continuous symmetry turns each minimum into a connected region rather than a lone point — a structural explanation for the empirically observed mode connectivity between independently trained networks [§sec_3_1].

## Intuition {#intuition}

Think of a trained network's minimum not as a single point but as a shape. If the weights can be continuously rotated, rescaled, or otherwise transformed without changing the function the network computes, the loss stays exactly the same along that whole path [§sec_3_1].

That path is an orbit. When the transformations form a Lie group, the orbit is usually a positive-dimensional surface rather than an isolated point [§sec_3_1].

Two networks trained independently by SGD can land at different points on the same orbit, or on orbits joined through the loss landscape — giving a symmetry-based reason why low-loss paths between separately trained solutions exist [§sec_3_1].

## Mechanics {#mechanics}

**Definition:** a symmetry is continuous when the group $G$ acting on parameter space $\Theta$ is a Lie group and the action is continuous. The orbit of a point $\theta$ is $O(\theta) = \{\theta' \in \Theta \mid \theta' = g \cdot \theta \text{ for some } g \in G\}$ [§sec_3_1].

**Why positive-dimensional orbits create flat directions:** the loss is constant on an orbit by construction, so when $G$ is a Lie group the orbit generically has positive dimension, and every direction tangent to it is a flat direction of the loss surface [§sec_3_1].

Empirical work first showed that independently trained networks can be joined by low-loss curves in parameter space, an observation called mode connectivity, later extended to multi-dimensional low-loss volumes connecting solutions found by SGD [§sec_3_1].

**Why the identity component matters:** the loss stays constant along each orbit, so two minima found by SGD are automatically connected by a symmetry transformation whenever the group action is continuous [§sec_3_1].

That guarantee needs one more piece: the connecting group element must lie in the identity component — the part of $G$ continuously joined to the identity — because only that component supplies a continuous path of parameters, each one still at the minimum, from one point to the other [§sec_3_1].

Not every point within a minimum is related to another by a symmetry transformation, and connectivity observed between independently trained networks may also arise from mechanisms other than symmetry — so symmetry is a sufficient explanation for mode connectivity, not the only possible one [§sec_3_1].

**When topology transfers directly:** if a loss level set is homeomorphic to the symmetry group itself via the group action — as happens in linear networks with invertible weight matrices — the level set inherits topological properties such as connectedness straight from the group [§sec_3_1].

Zero-loss curves generated by continuous group actions, together with dimension bounds derived from orbit dimensions, are further evidence that symmetry dictates the loss surface's flat directions [§sec_3_1].

A visualization of the set of functionally equivalent parameters in ReLU networks shows the expected permutation and scaling symmetry, plus additional structure suggesting more complex symmetries beyond those two [§sec_3_1].

## The Math {#the-math}

The paper presents the orbit as a set rather than a numerical formula, so the quantitative content here is what that set's dimension implies for the loss surface around a minimum [§sec_3_1].

```annotated-eq
  - tex: "g \\cdot \\theta"

  - tex: "G"
    role: 3

```

**Dimension counting:** if $G$ has $d$ independent continuous parameters, the orbit through a generic $\theta$ is generically a $d$-dimensional submanifold of $\Theta$, so it contributes $d$ locally flat directions to the loss surface at that minimum [§sec_3_1].

**Boundary case:** if $G$ is trivial — no continuous parameters at all — the orbit collapses to the single point $\theta$, recovering an isolated minimum with zero flat directions; this is the discrete-symmetry limit, where connectivity from symmetry alone disappears [§sec_3_1].
