# DAG Terminology
## TL;DR {#tldr}
This concept collects the vocabulary needed to talk precisely about directed acyclic graphs (DAGs) — parents, children, paths, colliders, d-separation, Markov equivalence — so that Structural Intervention Distance (SID) can be defined rigorously on top of it. It is foundational rather than novel: SID's correctness and interpretation as an evaluation metric for causal graphs depend on these definitions being fixed unambiguously before any distance is computed.

## Intuition {#intuition}
Before you can measure how "wrong" an estimated causal graph is compared to a true one, you need shared, unambiguous language for what a graph even claims about the world: who is a parent of whom, which paths carry information, which paths are blocked, and when two differently-drawn graphs actually encode the same independence structure. This last point — Markov equivalence — matters because SID needs to distinguish genuine structural errors from harmless relabelings of graphs that are statistically indistinguishable. The terminology here is the scaffolding that makes the later SID definition well-posed.

## Mechanics {#mechanics}
A graph consists of nodes and edges, with a subgraph relation (⊆) and proper subgraph relation defined by containment of nodes and edges; parents, children, and adjacency are defined locally around each node, and a graph is fully connected if every pair of nodes is adjacent [§sec_7]. Edges are classified as undirected (i, j) when both i→j and j→i hold, or directed (i→j) otherwise, and the skeleton of the graph is the edge set with direction stripped away, giving a size measure that counts an undirected edge once [§sec_7]. A path is a sequence of distinct adjacent vertices; when every edge on the path points the same way it is a directed path, making the endpoint a descendant of the start and the start an ancestor of the endpoint, with non-descendants collected into a separate set [§sec_7]. A collider on a path is a node where both neighboring edges point into it, and a semi-directed cycle is a path returning to its start with at least one directed edge oriented consistently around the loop [§sec_7]. These building blocks classify the graph itself: a PDAG has no directed cycle, a chain graph has no semi-directed cycle, nodes linked purely by undirected edges are equivalent and form a chain component, and a DAG is a PDAG whose edges are all directed [§sec_7]. Blocking and d-separation are defined path-by-path through a conditioning set Z, either via a non-collider in Z or a collider whose descendants (including itself) avoid Z, and two disjoint node sets are d-separated by Z when every connecting path is blocked [§sec_7]. Markov and faithfulness conditions tie this graphical structure to a distribution P: Markov means every d-separation implies a matching conditional independence, faithfulness means the converse also holds, and the set of distributions Markov to a DAG G is denoted with the entailed independencies fixed by G's d-separations [§sec_7]. Two DAGs are Markov equivalent exactly when they entail the same set of d-separations, and an entire equivalence class can be summarized by a completed PDAG whose directed edges are common to all class members and whose undirected edges appear in some members with each orientation [§sec_7].
