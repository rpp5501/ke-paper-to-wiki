# Feed-Forward Layers as Attention over Parameters
## TL;DR {#tldr}
The Transformer's position-wise feed-forward networks can be reinterpreted as a special case of attention: instead of attending over a sequence of activations, they "attend" over fixed, trainable parameter matrices that act as keys and values, with ReLU standing in for softmax. This reframing lets the two mechanisms — feed-forward and attention — be swapped for each other, and experiments show that replacing the feed-forward sublayer with real multi-head attention over trainable key/value parameters gives roughly the same translation quality.

## Intuition {#intuition}
A position-wise feed-forward network, which builds on the standard Position-wise Feed-Forward Networks used throughout the Transformer, expands each token's representation with one matrix, applies a nonlinearity, then compresses it back down with a second matrix. Ordinary attention does something structurally similar: it compares a query against a set of keys, turns the comparison scores into weights, and uses those weights to combine a set of values. The insight here is that the two computations line up almost exactly if you treat the rows of the feed-forward network's first weight matrix as "keys," the rows of its second weight matrix as "values," and replace the softmax weighting with a ReLU. Under this lens, a feed-forward layer isn't a fundamentally different tool from attention — it's attention where the "memory" being attended to is a fixed, learned set of parameters rather than the other tokens in the sequence.

## Mechanics {#mechanics}
The comparison starts from the standard feed-forward formula, two linear transformations with a ReLU in between, set side by side with the formula for simple dot-product attention with biases and scaling omitted [eq_6]. Matching the two formulae term by term, the rows of the trainable matrices $W_1$ and $W_2$ play the role of keys and values respectively, and ReLU substitutes for the softmax compatibility function [§sec_9]. Motivated by this parallel, the authors built an actual multi-head-attention-over-parameters sublayer: it is identical to ordinary multi-head attention, except that the "keys" and "values" fed into each head are trainable parameters rather than projections of the previous layer's activations, and these parameter values are scaled up so their magnitude resembles that of real activations [§sec_9]. Two configurations were tested, one with $h=8$ heads, $d_k=d_v=64$, and 64 key-value pairs per head, and another with $h=16$ heads and $d_k=d_v=64$ with only 32 key-value pairs per head; both were sized to match the parameter count of the base model's feed-forward sublayer [§sec_9]. On the English-to-German newstest2013 development set, the 8-head configuration scored slightly worse than the base model (PPL 4.92, BLEU 25.5 vs. base BLEU 25.8), while the 16-head configuration scored slightly better, but training step time grew about 30% longer in the attention version despite matching theoretical compute [§sec_9].

## The Math {#the-math}
The core algebraic move is a direct comparison of the two sublayer formulas: $\mathrm{FFN}(x, W_1, W_2) = \mathrm{ReLU}(xW_1)W_2$ against $A(q, K, V) = \mathrm{Softmax}(qK^T)V$ [eq_6]. In both, an input vector is first compared against a bank of vectors ($W_1$'s rows, or $K$) to produce a set of scores, those scores are passed through a nonlinearity (ReLU vs. Softmax), and the result is used to linearly combine a second bank of vectors ($W_2$'s rows, or $V$) [§sec_9]. The parameter count of the resulting attention-over-parameters sublayer, including its query and output projections, was set to exactly match the position-wise feed-forward network it replaced, which is why the two experimental configurations vary $h$, $d_k$/$d_v$, and the number of key-value pairs against each other while holding total parameters fixed [§sec_9]. The local context also derives the scaling justification used elsewhere in attention — for independent random vectors $\vec{u}, \vec{v}$ with zero mean and unit variance, $E[\langle \vec{u}, \vec{v}\rangle] = 0$ [eq_7] and $\mathrm{Var}(\langle \vec{u}, \vec{v}\rangle) = d_k$ [eq_8] — which is why dot products are divided by $\sqrt{d_k}$; this variance argument is the same normalization logic that motivates scaling up the trainable parameter values in the attention-over-parameters sublayer so they resemble real activations [§sec_9].
