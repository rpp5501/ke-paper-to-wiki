# Symbolic Reasoning
## TL;DR {#tldr}
Chain-of-thought prompting lets large language models perform toy symbolic-manipulation tasks — concatenating the last letters of names and tracking a coin's state through a sequence of flips — that standard prompting cannot solve, and lets them generalize to more reasoning steps than any few-shot exemplar showed. This ability appears only once models reach roughly 100B parameters; smaller models fail even the in-domain version of the task.

## Intuition {#intuition}
A human handed "concatenate the last letters of Marc Chagall" doesn't need to relearn the rule for a four-word name — they just repeat the same two-letter-grab-and-glue move one more time. Chain-of-thought gives a language model the same crutch: the few-shot exemplar shows the model the move itself, so applying it to a longer input is repetition, not invention.

Standard prompting denies the model that scaffold, forcing it to jump straight from name to answer in one step. That is exactly where it breaks down on inputs longer than anything it was shown.

## Mechanics {#mechanics}
- The last-letter-concatenation task asks the model to extract and join the last letter of each word in a full name generated by combining top first and last names from census data [§sec_5]
- The coin-flip task asks whether a coin initialized heads-up is still heads-up after a sequence of people who each either flip it or leave it alone [§sec_5]
- Few-shot exemplars for both tasks are manually composed chains of thought rather than natural text scraped from a corpus, since the task structure is fully specified by the authors [§sec_5]
- Each task has an in-domain test set matching the exemplars' step count and an out-of-distribution (OOD) test set with more steps — last-letter names grow from two words in the exemplars to three and four words at test time, and the coin-flip task similarly increases the number of potential flips [§sec_5]
- In-domain with 540B, chain-of-thought prompting reaches almost 100% solve rate; standard prompting already solves coin flip at 540B, though not at 137B [§sec_5]
- Smaller models fail the in-domain tasks even with chain-of-thought, showing that reliably repeating a demonstrated abstract procedure on unseen symbols only appears around 100B parameters [§sec_5]
- On the OOD test sets, standard prompting fails outright for both tasks, while chain-of-thought prompting produces upward-sloping scaling curves — accuracy climbs with model size even though it stays below the in-domain numbers [§sec_5]

## The Math {#the-math}
Last-letter concatenation on an n-word name performs n letter extractions and n−1 concatenations, so the chain of thought's step count grows as O(n) [§sec_5]. The few-shot exemplars fix n = 2, so solving the OOD sets at n = 3 and n = 4 means repeating that same extract-then-concatenate step rather than learning a new operation [§sec_5].

The coin-flip task's final state is a parity of the k independent flip decisions: heads survives only if an even number of people chose to flip [§sec_5]. Computed in one pass, parity has no local shortcut: any one of the k decisions can flip the final answer, so the model must implicitly track all k before responding [§sec_5].

Chain-of-thought replaces that single pass with an explicit loop: state₀ = heads, and for i = 1…k, state_i = flip(state_{i−1}) if the i-th person flips and state_i = state_{i−1} otherwise, terminating after k steps with state_k as the final answer [§sec_5].

Each update touches only the running state and one decision, so the identical rule handles k = 2, the length seen in the exemplars, or k = 4 at test time, unchanged — which is why chain-of-thought's OOD accuracy rises with scale while standard prompting, with no intermediate state to fall back on, fails outright [§sec_5].

## Go Deeper {#go-deeper}
The paper frames both tasks as intentionally "toy" — the exemplars already hand the model a perfect solution template, so in-domain success only requires substituting new symbols into a known procedure [§sec_5]. What's notable is that this substitution alone is enough to separate small and large models: the abstract-manipulation ability needed to run the template reliably on unseen symbols does not appear until roughly 100B parameters, and OOD length generalization — running the template more times than demonstrated — is strictly harder still, landing below in-domain accuracy even in the best-scoring models [§sec_5]. This positions symbolic reasoning as a probe for whether chain-of-thought teaches a genuine procedure versus enabling memorized pattern completion: memorization would not extend past the demonstrated step count, while a learned procedure would.
