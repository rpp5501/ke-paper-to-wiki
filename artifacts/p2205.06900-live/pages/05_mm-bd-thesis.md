# MM-BD: Maximum-Margin Backdoor Detection
## TL;DR {#tldr}
MM-BD is a post-training defense that flags whether a trained classifier has been backdoored, without needing clean labeled samples, a pool of candidate backdoor pattern (BP) types, or access to the original training set. It works by measuring how atypical the "maximum margin" of each class's output landscape is, using a statistic estimated purely from random probing vectors, and then running an unsupervised anomaly detector over the per-class statistics to decide which class (if any) is the attacker's target.

## Intuition {#intuition}
Backdoor attacks are hard to catch because a successful one leaves clean-sample accuracy untouched — the classifier behaves normally until the secret trigger pattern appears, at which point it snaps to the attacker's target class. Most existing post-training defenses try to reverse-engineer the actual trigger pattern or train shallow "meta-classifiers" on examples of known attack types, which means they only work well when the real attack resembles the patterns they were designed or trained around. MM-BD instead asks a more indirect but more general question: independent of what the trigger looks like, does the target class's decision region have an unusually easy, unusually large margin to reach from arbitrary points in input space? A backdoor effectively carves an oversized "shortcut" into one class, and that shortcut shows up as an atypically large maximum margin for that class relative to the others — a signature that doesn't depend on assuming a particular trigger shape, size, or embedding method up front.

## Mechanics {#mechanics}
The paper targets a post-training scenario where the defender only has the trained classifier itself — no access to the (possibly poisoned) training set, no unattacked reference classifier to calibrate against, and critically, unlike prior post-training defenses, no requirement for a set of clean legitimate samples from all classes [§sec_1]. This is a deliberately harder and more realistic setting than the training-time sanitization defenses that require intervening before or during training, which is infeasible once the training authority itself may be compromised [§sec_1].

The core detection procedure estimates a maximum margin (MM) statistic for each class using a set of random vectors, generated independently of any assumption about the backdoor pattern's type or embedding function, and then feeds these per-class statistics into an unsupervised anomaly detector to infer which class, if any, is a backdoor target [§sec_1]. Because the random-vector estimation makes no reference to a specific BP family, the method sidesteps the core limitation of reverse-engineering-based defenses (which bake an assumed embedding function into their optimization) and of meta-classifier-based defenses (which only generalize to BP types present in their training pool) [§sec_1].

A secondary mechanic addresses what to do once a backdoor is detected but no trustworthy replacement classifier is available: the paper proposes suppressing the maximum possible activations of individual neurons using a set of per-neuron optimized upper bounds, chosen so that clean-sample accuracy is preserved while the backdoor's exploitable activation pathways are capped [§sec_1]. This mitigation step is also class/pattern-agnostic, consistent with the detector's design philosophy [§sec_1].
