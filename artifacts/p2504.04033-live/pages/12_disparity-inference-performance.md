# Disparity Inference Attack Performance
## TL;DR {#tldr}
This section reports how well the Disparity Inference Attack predicts which subgroups of a population are most vulnerable to attribute inference, and shows that its rankings track real attack success far more closely than a baseline that relies on an auxiliary labeled dataset.

## Intuition {#intuition}
Not every subgroup in a dataset is equally exposed to attribute inference: some groups have attributes that are easy for an attacker to guess from a model's outputs, others don't. The Disparity Inference Attack was built to rank groups by vulnerability without needing ground-truth sensitive labels, and this experiment asks the natural follow-up question: does that ranking actually match which groups get successfully attacked in practice? The evaluation manufactures a spread of vulnerability levels by controlling how strongly the sensitive attribute correlates with the model's output in each group, then checks whether the attack's predicted ordering lines up with real attack outcomes on both a census-style dataset and a healthcare-style dataset.

## Mechanics {#mechanics}
For Census-19, marital status is the sensitive attribute and records are split into 51 groups (indexed by state), while for Texas-100X the sensitive attribute splits records into 10 groups; in both cases each group is assigned a target correlation between the sensitive attribute and the output so that vulnerability varies deliberately across groups, with up to 1,000 records sampled per group while preserving that correlation, and a target model trained per subset [§sec_6_3]. The Disparity Inference Attack is then run to compute an angular difference for each group and rank groups by that value, and plotting angular difference against actual attack accuracy for both CSMIA and LOMIA shows a strong association: higher angular difference predicts stronger real attack performance, and lower angular difference predicts weaker performance [§sec_6_3]. As a comparison point, a baseline ranking attack is defined in which the adversary has an auxiliary dataset the same size as the training set with all sensitive values known, drawn from a differently-distributed sample, and ranks groups by running CSMIA directly on that auxiliary data [§sec_6_3].

## The Math {#the-math}
The local context for this section reports evaluation results rather than defining new formulas, so no [eq_N]-tagged equations are reproduced here [§sec_6_3]. Ranking quality is measured with Kendall's Tau and Spearman's Rank Correlation, both bounded in [-1, 1], where values near 0 indicate poor ranking agreement and values far from 0 (in either direction) indicate good agreement, since a strongly negative correlation still reflects a systematic — merely reversed — ordering rather than a lack of useful signal [§sec_6_3]. On Census-19, the Disparity Inference Attack achieves Kendall's Tau of 0.6914 (p = 1.39e-12) and Spearman R of 0.8767 (p = 7.23e-17) against CSMIA outcomes, and 0.7579 / 0.9104 against LOMIA outcomes, compared to the baseline's near-zero, statistically insignificant correlations (e.g., Kendall's Tau -0.0759, p = 4.37e-01) [§sec_6_3]. On Texas-100X, the attack reaches Kendall's Tau -0.7778 (p = 9.46e-04) and Spearman R -0.9273 (p = 1.12e-04) for CSMIA, with comparable magnitudes for LOMIA, again with the baseline's correlations far weaker and not statistically significant [§sec_6_3].
