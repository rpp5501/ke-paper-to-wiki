# Comparing Correlation between Groups

## TL;DR {#tldr}
This concept explains how an attacker can rank demographic groups by how vulnerable they are to attribute inference, simply by looking at how "confident" a model's predictions become when the sensitive attribute is toggled. Groups whose sensitive attribute is strongly correlated with the class label produce a bigger swing in confidence between attribute values, and that swing is visible without ever knowing the true correlation — making it a practical tool for uncovering high-risk groups.

## Intuition {#intuition}
The core idea builds on the broader finding that correlation between a sensitive attribute and the class label is a key factor driving vulnerability: the more skewed a group's sensitive-attribute values are toward one class label, the more the trained model "leans on" that attribute when deciding how confident to be. An adversary doesn't need to compute this correlation directly — they can instead query the same record twice, once for each sensitive-attribute value, and look at the gap between the two confidence scores. A large, consistent gap signals a strongly imbalanced (highly correlated) group; a small gap signals a more balanced, lower-risk group. This turns an invisible statistical property of the training data into something observable purely through model outputs.

## Mechanics {#mechanics}
The attack starts from a simple case: a binary sensitive attribute (`yes`/`no`) and a binary class label (`True`/`False`). If the dataset is strongly correlated, the `True` class contains far more `yes` records than `no` records, so the model becomes biased toward higher confidence for `True` when the sensitive attribute is set to `yes`; the size of this confidence gap tracks the degree of imbalance in the group [§sec_4_2].

To visualize this, confidence scores are plotted for records where every query variant still yielded the correct predicted label, using hexagon-binned bivariate histograms with univariate marginal histograms on each axis, comparing groups such as Male, Female, and White with correlations of -0.6, -0.4, and -0.5 respectively [§sec_4_2]. Each class's distribution forms a comet shape with a dense head near the top-right corner and a tail whose direction differs by class: High Income records tilt horizontally (more confident when Married), while Low Income records tilt vertically, and the tilt angle itself shifts gradually from high-correlation to low-correlation groups [§sec_4_2].

Naively comparing correlation by subtracting the confidence-score distributions between class labels is unreliable, because the dense shared region near the 0.95–1.0 confidence range dominates and distorts the difference calculation [§sec_4_2]. Instead, the method fits a regression line to each class's tail points per group and measures the angular difference between the two lines (per class label), since the tails — not the crowded head — are what actually differentiate correlation levels between groups [§sec_4_2]. For sensitive attributes with more than two values, this generalizes to regression lines drawn in an n-dimensional space (n = number of attribute values), and for multi-class outputs the average pairwise angular difference across all class-label regression lines is used; non-discrete sensitive attributes are handled by binning value ranges and substituting bin means, following Mehnaz et al.'s approach [§sec_4_2].

## The Math {#the-math}
The local context describes this comparison procedure qualitatively — via regression-line angles and confidence-score distributions — rather than giving a formal equation, so there is no [eq_N] block to reproduce for this concept [§sec_4_2]. The quantitative anchors that do appear are the per-group correlation values used to validate the method (Male: -0.6, Female: -0.4, White: -0.5), which serve as ground truth against which the observed angular differences in the regression lines are compared [§sec_4_2].
