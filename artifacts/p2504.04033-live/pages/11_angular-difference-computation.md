# Computing Angular Difference
## TL;DR {#tldr}
Computing angular difference is the core measurement step of the attack methodology: it turns a target model's confidence scores — collected while the sensitive attribute is flipped — into a single number that captures how much a record's prediction confidence swings with that attribute. This score is the input both the Disparity Inference Attack and the Targeted Attribute Inference Attack rely on to identify which records are most vulnerable to attribute leakage.

## Intuition {#intuition}
Imagine asking the model the same question twice, once pretending the sensitive attribute is one value and once pretending it's the other, and watching how much its confidence answer moves. If the model barely notices the swap, the sensitive attribute probably isn't doing much work in its decision, and the record is comparatively safe. If the confidence swings sharply, the model is effectively leaking the sensitive attribute through its outputs, which is exactly the disparity that downstream inference attacks exploit.

## Mechanics {#mechanics}
The process starts by generating, for each original record, a set of variant records that differ only in the sensitive attribute value, and querying the target model with each variant to collect confidence scores; this collection is what the paper calls the confidence matrix [§sec_5_1]. While collecting these scores, a boolean prediction correctness vector is tracked for each record, marking whether the model's predictions were correct across all sensitive-attribute variants — records are only kept for the angular-difference computation when predictions are correct for any sensitive attribute value, since these are the cases where confidence differences are believed to carry real signal about the correlation between the sensitive attribute and the outcome [§sec_5_1]. From the surviving records, confidence scores are grouped separately for each class label, using only records whose correctness vector qualifies, forming per-class collections of confidence scores [§sec_5_1]. A regression line is then fit to each per-class collection, with the dimension corresponding to the positive sensitive-attribute value used as the regression output, and the angular difference is defined as the mean angular distance between these fitted lines across class labels [§sec_5_1].
